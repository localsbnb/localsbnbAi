## 这是什么？

房子早就在 **路客云** 里接着 **Airbnb、Booking.com、Agoda、Trip.com**。LocalsBnb 是同一套系统的海外名字——给不想再活在后台里的房东用。

以前：解锁手机，打开四个 App，等日历转圈，把名字抄进备忘录，302 到底是谁又忘了。

现在：打开你本来就在聊的窗口，像喊值班经理一样说话。

> 「今天谁到店？」  
> 「海景房周六还有吗？」  
> 「给 Anna 办理入住——先给我看是哪一单。」

**Just say.** LocalsBnb 藏在你的 AI 后面，拉的是店里的真客人、真房间、真数字。人还是你，点来点去的那部分可以退休了。

## 可以在哪些软件上用？

只要这个软件能「添加工具」，就能接 LocalsBnb。**装一次**，以后在这个软件里聊天，都能管店。

**电脑上最常用**

| 软件 | 谁会更顺手 |
|------|------------|
| **Claude**（Claude Desktop） | 最适合第一次：用大白话聊就行 |
| **ChatGPT** | 你本来每天就开 ChatGPT |
| **Cursor** | 你本来就在 Cursor 里干活 |
| **Windsurf** | 同样是能加工具的 AI 编辑器 |
| **VS Code + GitHub Copilot** | 电脑里已经是 VS Code |

**用你已经在聊的窗口**

海外店东多数留在 Claude / ChatGPT / Cursor。OpenClaw 和 Hermes 不是海外默认安装——只有你已经在用「活在聊天软件里的助手」时，它们才有意义。

| 你在哪说话 | LocalsBnb 怎么到那儿 |
|------------|----------------------|
| **微信 / 企微 / 飞书 / 钉钉** | 国内：同一对码加进 OpenClaw 或 Hermes，走路都能问 |
| **WhatsApp / LINE / Telegram / iMessage** | 海外：只有你已经用 OpenClaw 或 Hermes 当这个聊天的助手时。同一对码。没有这套，就从 Claude / ChatGPT / Cursor 开始 |

![多数人走左边：Claude / ChatGPT / Cursor。右边只有已经用 OpenClaw 或 Hermes 接微信、WhatsApp 时才走。](assets/localsbnb-doors.png)

选你**早上醒来就会点开**的那个。不要再下一个「酒店专用 App」。

## 到底能干什么？

### 一天里，你可以直接这样问

**7:10，人还在外地的床上**  
「今天预抵、在住、预离，一口气报给我。」  
一条回复：名字、房间、日期。保洁还没出门，你已经发完微信。

**8:00，前台交班**  
「11 点前谁退房？还有没有脏房？」  
新来的不用学两小时系统。他们本来就会问人。

**10:30，客人打电话**  
「林先生能不能提前入住？那间房上一拨几点走？」  
三十秒给答案，不是「你等我开电脑」。

**12:00，盯周末**  
「这周五到周日，爱彼迎什么价？Agoda 呢？」  
一口气对比渠道，不用登四个后台。

**15:00，保洁在走廊里问**  
「现在哪些房是空的、是干净的？」  
不用把密码给她。你看一眼，告诉她。

**18:00，业主群催报表**  
「这周入住怎么样？均价和营收呢？」  
数字按你在路客云给门店设的**语言和货币**回来，这边不用再配。

**21:40，客人要多住一晚**  
「帮他们续住一晚，行不行？」*(海外店)*  
AI 先摊开：**谁、哪间、哪几天**。你说行，才办。

**22:15，排错房了**  
「今晚这位从 201 换到 305。」*(海外店)*  
还是先点名是哪一单，你确认，再换。

**节假日 / 下雨 / 隔壁有演唱会**  
「这周满房情况和上周比呢？」  
涨不涨周末价，靠眼前的一周，不是靠感觉。

**新人第一天**  
不用背菜单。记住三句就够：*今天谁到、今天房间、这周数字。*

### 帮客人办手续——仅海外店

LocalsBnb 海外店可以让 AI **办理入住、退房、续住、换房**。

它不会偷偷做。一定先给你看是哪位客人、哪几天。你说「就是这一单」，才生效。

![先给你看是哪一单，你点头，再动手。](assets/localsbnb-confirm.png)

**国内店：** 上面这些「店里怎么样」都能问。**办理入住、退房、续住、换房，国内版暂时还不支持。** 取消订单、改挂牌价、同步日历，请仍在路客云里操作。

## 怎么开始？（三步）

### 1. 在路客云拿两个码

登录路客云，复制：

- **APP_SECRET**：你的密钥  
- **APP_ID**：你的店铺编号  

只放自己兜里，别发班级群。

### 2. 丢进你选好的 AI

打开 **Claude、ChatGPT 或 Cursor**，找到「添加工具 / MCP」，贴上下面，两行换成你的：

```json
{
  "mcpServers": {
    "LocalsBnb MCP": {
      "command": "npx",
      "args": ["--yes", "localsbnb-mcp-server"],
      "env": {
        "APP_SECRET": "<你的 APP_SECRET>",
        "APP_ID": "<你的 APP_ID>"
      }
    }
  }
}
```

| 你用的是… | 一般加在哪 |
|-----------|------------|
| Cursor | 设置 → MCP，或 `mcp.json` 文件 |
| Claude Desktop | 设置 → 自定义工具 / MCP |
| ChatGPT | 设置 → 应用 / 开发者工具（看你的套餐） |
| 微信 / 飞书（国内） | 让装 OpenClaw 或 Hermes 的人，填上同一对码 |
| WhatsApp / LINE / iMessage | 只有 OpenClaw 或 Hermes 已经在这个聊天里说话时——同一对码。否则用 Claude / ChatGPT / Cursor |

懒得找入口？直接对 AI 说：

> 帮我安装 localsbnb-mcp-server，这是我的 APP_SECRET 和 APP_ID。

### 3. 像房东一样说话，别像程序员

- 「今天谁到店？」  
- 「看看今天的房间。」  
- 「这周爱彼迎什么价？」  
- 「这周经营怎么样？」  
- 「给 Maria 办理入住——先给我看是哪一单。」*(海外)*

回答跟路客云里**门店语言**走。这里不用再选一遍中文还是日文。
