# LocalsBnb

**言えば、宿が答える。**  
LocalsBnb のアプリは不要。専用のパソコンも不要。いつもの AI が、そのままフロントになります。

## これは何？

物件はすでに **LocalsBnb** で **Airbnb、Booking.com、Agoda、Trip.com** につながっています。管理画面の中で暮らしたくないホストのためのものです。

以前：スマホを開く、アプリを四つ開く、カレンダーが回るのを待つ、名前をメモして、302 は誰だっけと忘れる。

今：いつものチャットを開いて、当番のマネージャーに話しかけるように言う。

> 「今日、誰が来る？」  
> 「海側の部屋、土曜空いてる？」  
> 「Anna をチェックインして。先に予約を見せて。」

**Just say.** LocalsBnb は AI の後ろにいて、本物のゲスト、部屋、数字を取りにいきます。考えるのはあなた。クリック作業は、もういりません。

![あなたが話す。AI が LocalsBnb に聞く。LocalsBnb が本物の予約と部屋を返す。](assets/localsbnb-flow.png)

## どのソフトで使える？

「ツールを追加できる」ソフトなら、LocalsBnb を入れられます。**一度入れれば**、そのアプリでの会話が、そのまま宿の仕事になります。

**パソコンでよく使うもの**

| アプリ | 向いている人 |
|--------|----------------|
| **Claude**（Claude Desktop） | 初めてならこれ。普通の言葉で話せばいい |
| **ChatGPT** | 毎日 ChatGPT を開いている人 |
| **Cursor** | すでに Cursor で仕事している人 |
| **Windsurf** | 同じくツールを足せる AI エディタ |
| **VS Code + GitHub Copilot** | パソコンがもう VS Code の人 |

**いつものチャットでも**

海外のホストは、だいたい Claude / ChatGPT / Cursor のままです。OpenClaw と Hermes は海外の標準インストールではありません。チャットアプリの中ですでに助手を動かしている人向けです。

| 話す場所 | LocalsBnb の入り方 |
|----------|-------------------|
| **WeChat / 企業微信 / Feishu / DingTalk** | 中国：同じ二つのコードを OpenClaw または Hermes へ。歩きながら聞ける |
| **WhatsApp / LINE / Telegram / iMessage** | 海外：そのチャットの助手がすでに OpenClaw または Hermes のときだけ。同じ二つのコード。なければ Claude / ChatGPT / Cursor から |

![多くの人は左：Claude / ChatGPT / Cursor。右は、OpenClaw や Hermes がすでに WeChat や WhatsApp にいるときだけ。](assets/localsbnb-doors.png)

朝、無意識に開くアプリを選んでください。五つ目の「宿アプリ」は要りません。

## 実際に何ができる？

### 一日、こう聞いてみてください

**7:10、まだ別の街のベッド**  
「今日の到着、滞在中、出発をまとめて。」  
名前、部屋、日程が一つの返事に。清掃に連絡してから、コーヒー。

**8:00、フロントの引き継ぎ**  
「11時までに出る人は？汚い部屋は残ってる？」  
新人に二時間の研修は不要。質問の仕方は、もう知っています。

**10:30、電話のゲスト**  
「林さん、早めに入れる？その部屋の前の人は何時に出る？」  
三十秒で答える。「パソコン開きます」とは言わない。

**12:00、週末の値段**  
「金曜から日曜、Airbnb はいくら？Agoda は？」  
チャネルを四つ開かず、一息で比べる。

**15:00、廊下のハウスキーパー**  
「今、空いててきれいな部屋は？」  
パスワードを渡さなくていい。あなたが見て、伝える。

**18:00、オーナーのグループ**  
「今週の稼働、平均単価、売上は？」  
数字は LocalsBnb で施設に設定した**言語と通貨**のまま。こちらで再設定しません。

**21:40、もう一晩**  
「延長できる？」*(海外施設)*  
AI が先に出す：**誰、どの部屋、どの日程**。あなたが「それで」と言ってから動く。

**22:15、部屋を間違えた**  
「今夜の人を 201 から 305 へ。」*(海外施設)*  
同じ。予約を名指し、確認、それから変更。

**祝日 / 雨 / 隣でライブ**  
「今週の埋まり具合、先週と比べて？」  
週末を上げるかは、感覚ではなく、目の前の一週間で決める。

**新人の初日**  
メニューは覚えなくていい。三言で足りる。*今日の到着、今日の部屋、今週の数字。*

### 宿泊の手続き — 海外の LocalsBnb 施設だけ

AI に **チェックイン、チェックアウト、延長、部屋変更** を頼めます。

勝手にはやりません。ゲストと日程を先に見せます。「それで合ってる」のあとだけ実行します。

![先に予約を見せる。あなたがうなずく。それから実行。](assets/localsbnb-confirm.png)

**中国国内の施設：** 「今どうなってる？」は同じように聞けます。**入退室・延長・部屋変更は、中国版ではまだ使えません。** キャンセル、掲載価格、カレンダー同期は、今も LocalsBnb 側です。

## 始め方（三ステップ）

### 1. LocalsBnb で二つのコードを取る

LocalsBnb にログインしてコピーします。

- **APP_SECRET** — 鍵  
- **APP_ID** — 施設番号  

自分だけ。グループには貼らない。

### 2. 選んだ AI に入れる

**Claude、ChatGPT、Cursor** を開き、ツール / MCP を追加して、下を貼り、二行を差し替えます。

```json
{
  "mcpServers": {
    "LocalsBnb MCP": {
      "command": "npx",
      "args": ["--yes", "localsbnb-mcp-server"],
      "env": {
        "APP_SECRET": "<your APP_SECRET>",
        "APP_ID": "<your APP_ID>"
      }
    }
  }
}
```

| 使っているもの | だいたいここ |
|----------------|--------------|
| Cursor | 設定 → MCP、または `mcp.json` |
| Claude Desktop | 設定 → カスタムツール / MCP |
| ChatGPT | 設定 → アプリ / 開発者（プランによる） |
| WeChat / Feishu（中国） | OpenClaw または Hermes を入れた人に、同じ二つのコードを渡す |
| WhatsApp / LINE / iMessage | そのチャットですでに OpenClaw または Hermes が話しているときだけ。同じ二つのコード。なければ Claude / ChatGPT / Cursor |

設定が面倒なら、AI に言ってください。

> localsbnb-mcp-server を入れて。APP_SECRET と APP_ID はこれ。

### 3. ホストのように話す。プログラマのように話さない

- 「今日の到着は？」  
- 「今日の部屋を見せて。」  
- 「今週の Airbnb の値段は？」  
- 「今週どう？」  
- 「Maria をチェックイン。先に予約を見せて。」*(海外)*

返事は LocalsBnb の**施設の言語**に従います。ここで日本語か英語かを選び直す必要はありません。
