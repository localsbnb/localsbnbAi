## 這是什麼？

房子早就在 **路客云** 裡接著 **Airbnb、Booking.com、Agoda、Trip.com**。LocalsBnb 是同一套系統的海外名字——給不想再活在後台裡的房東用。

以前：解鎖手機，打開四個 App，等日曆轉圈，把名字抄進備忘錄，302 到底是誰又忘了。

現在：打開你本來就在聊的視窗，像喊值班經理一樣說話。

> 「今天誰到店？」  
> 「海景房週六還有嗎？」  
> 「幫 Anna 辦理入住——先給我看是哪一筆。」

**Just say.** LocalsBnb 藏在你的 AI 後面，拉的是店裡的真客人、真房間、真數字。人還是你，點來點去的那部分可以退休了。

![你開口，AI 去問路客云，路客云帶回真實的訂單和房間。](assets/localsbnb-flow.png)

## 可以在哪些軟體上用？

只要這個軟體能「新增工具」，就能接 LocalsBnb。**裝一次**，以後在這個軟體裡聊天，都能管店。

**電腦上最常用**

| 軟體 | 誰會更順手 |
|------|------------|
| **Claude**（Claude Desktop） | 最適合第一次：用大白話聊就行 |
| **ChatGPT** | 你本來每天就開 ChatGPT |
| **Cursor** | 你本來就在 Cursor 裡工作 |
| **Windsurf** | 同樣是能加工具的 AI 編輯器 |
| **VS Code + GitHub Copilot** | 電腦裡已經是 VS Code |

**用你已經在聊的視窗**

海外房東多數留在 Claude / ChatGPT / Cursor。OpenClaw 和 Hermes 不是海外預設安裝——只有你已經在用「活在聊天軟體裡的助手」時，它們才有意義。

| 你在哪說話 | LocalsBnb 怎麼到那兒 |
|------------|----------------------|
| **微信 / 企微 / 飛書 / 釘釘** | 中國大陸：同一對碼加進 OpenClaw 或 Hermes，走路都能問 |
| **WhatsApp / LINE / Telegram / iMessage** | 海外：只有你已經用 OpenClaw 或 Hermes 當這個聊天的助手時。同一對碼。沒有這套，就從 Claude / ChatGPT / Cursor 開始 |

![多數人走左邊：Claude / ChatGPT / Cursor。右邊只有已經用 OpenClaw 或 Hermes 接微信、WhatsApp 時才走。](assets/localsbnb-doors.png)

選你**早上醒來就會點開**的那個。不要再下一個「飯店專用 App」。

## 到底能幹什麼？

### 一天裡，你可以直接這樣問

**7:10，人還在外地的床上**  
「今天預抵、在住、預離，一口氣報給我。」  
一則回覆：名字、房間、日期。清潔還沒出門，你已經傳完訊息。

**8:00，櫃檯交班**  
「11 點前誰退房？還有沒有髒房？」  
新來的不用學兩小時系統。他們本來就會問人。

**10:30，客人打電話**  
「林先生能不能提前入住？那間房上一批幾點走？」  
三十秒給答案，不是「你等我開電腦」。

**12:00，盯週末**  
「這週五到週日，Airbnb 什麼價？Agoda 呢？」  
一口氣對比通路，不用登四個後台。

**15:00，清潔在走廊裡問**  
「現在哪些房是空的、是乾淨的？」  
不用把密碼給她。你看一眼，告訴她。

**18:00，業主群催報表**  
「這週入住怎麼樣？均價和營收呢？」  
數字按你在路客云給門店設的**語言和貨幣**回來，這邊不用再設。

**21:40，客人要多住一晚**  
「幫他們續住一晚，行不行？」*(海外店)*  
AI 先攤開：**誰、哪間、哪幾天**。你說行，才辦。

**22:15，排錯房了**  
「今晚這位從 201 換到 305。」*(海外店)*  
還是先點名是哪一筆，你確認，再換。

**假日 / 下雨 / 隔壁有演唱會**  
「這週滿房情況和上週比呢？」  
漲不漲週末價，靠眼前的一週，不是靠感覺。

**新人第一天**  
不用背選單。記住三句就夠：*今天誰到、今天房間、這週數字。*

### 幫客人辦手續——僅海外店

LocalsBnb 海外店可以讓 AI **辦理入住、退房、續住、換房**。

它不會偷偷做。一定先給你看是哪位客人、哪幾天。你說「就是這一筆」，才生效。

![先給你看是哪一筆，你點頭，再動手。](assets/localsbnb-confirm.png)

**中國大陸門店：** 上面這些「店裡怎麼樣」都能問。**辦理入住、退房、續住、換房，中國大陸版暫時還不支援。** 取消訂單、改掛牌價、同步日曆，請仍在路客云裡操作。

## 怎麼開始？（三步）

### 1. 在路客云拿兩個碼

登入路客云，複製：

- **APP_SECRET**：你的金鑰  
- **APP_ID**：你的店鋪編號  

只放自己口袋，別發到群組。

### 2. 丟進你選好的 AI

打開 **Claude、ChatGPT 或 Cursor**，找到「新增工具 / MCP」，貼上下面，兩行換成你的：

```json
{
  "mcpServers": {
    "LocalsBnb MCP": {
      "command": "npx",
      "args": ["--yes", "localsbnb-mcp-server"],
      "env": {
        "APP_SECRET": "<你的 APP_SECRET>",
        "APP_ID": "<你的 APP_ID>"
      }
    }
  }
}
```

| 你用的是… | 一般加在哪 |
|-----------|------------|
| Cursor | 設定 → MCP，或 `mcp.json` |
| Claude Desktop | 設定 → 自訂工具 / MCP |
| ChatGPT | 設定 → 應用程式 / 開發者工具（看你的方案） |
| 微信 / 飛書（中國大陸） | 讓裝 OpenClaw 或 Hermes 的人，填上同一對碼 |
| WhatsApp / LINE / iMessage | 只有 OpenClaw 或 Hermes 已經在這個聊天裡說話時——同一對碼。否則用 Claude / ChatGPT / Cursor |

懶得找入口？直接對 AI 說：

> 幫我安裝 localsbnb-mcp-server，這是我的 APP_SECRET 和 APP_ID。

### 3. 像房東一樣說話，別像工程師

- 「今天誰到店？」  
- 「看看今天的房間。」  
- 「這週 Airbnb 什麼價？」  
- 「這週經營怎麼樣？」  
- 「幫 Maria 辦理入住——先給我看是哪一筆。」*(海外)*

回答跟路客云裡**門店語言**走。這裡不用再選一次中文或日文。
