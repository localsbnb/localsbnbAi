# ツールと聞き方（海外）

| ツール | 聞き方の例 |
|--------|------------|
| `query_today_orders` | 今日の予約ボード |
| `query_pre_arrival_orders` | 今日の到着 |
| `query_in_house_orders` | 滞在中のゲスト |
| `query_pre_departure_orders` | 今日の出発 |
| `query_orders_by_date_range` | 今週の予約（`timeRange=this_week`） |
| `get_order_details_v2` | 注文詳細（返信にゲスト名必須） |
| `query_today_room_status` | 本日の部屋状況 |
| `query_room_status_new` | 今週の部屋カレンダー |
| `query_room_prices` | 今週のチャネル料金 |
| `query_operational_data_v2` | 今週の OCC / ADR / 売上 |

更新（海外のみ）：`check_in_order` / `check_out_order` / `extend_order` / `arrange_room`。確認後に `confirm=true`。キャンセルは第1期対象外。
