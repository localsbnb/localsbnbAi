# 工具與示例問法（海外）

| 工具 | 可以這樣問 |
|------|------------|
| `query_today_orders` | 今日訂單、今天待辦 |
| `query_pre_arrival_orders` | 今天預抵 |
| `query_in_house_orders` | 在住有誰 |
| `query_pre_departure_orders` | 今天預離 |
| `query_orders_by_date_range` | 本週訂單（`timeRange=this_week`） |
| `get_order_details_v2` | 查訂單詳情（回覆必須含客人姓名） |
| `query_today_room_status` | 今天房態 |
| `query_room_status_new` | 本週房態日曆 |
| `query_room_prices` | 本週通路房價 |
| `query_operational_data_v2` | 本週入住率／ADR／營收 |

寫操作（僅海外）：`check_in_order`、`check_out_order`、`extend_order`、`arrange_room`。先預覽，再 `confirm=true`。第一期不做取消。
