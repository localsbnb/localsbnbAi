# Alat dan contoh soalan (luar negara)

| Alat | Tanya seperti |
|------|----------------|
| `query_today_orders` | Papan pesanan hari ini |
| `query_pre_arrival_orders` | Siapa tiba hari ini |
| `query_in_house_orders` | Siapa sedang menginap |
| `query_pre_departure_orders` | Siapa berlepas hari ini |
| `query_orders_by_date_range` | Pesanan minggu ini (`timeRange=this_week`) |
| `get_order_details_v2` | Butiran pesanan (wajib nama tetamu) |
| `query_today_room_status` | Status bilik hari ini |
| `query_room_status_new` | Kalendar bilik minggu ini |
| `query_room_prices` | Harga saluran minggu ini |
| `query_operational_data_v2` | OCC / ADR / hasil minggu ini |

Tulis (luar negara sahaja): `check_in_order` / `check_out_order` / `extend_order` / `arrange_room`. Pratonton dulu, kemudian `confirm=true`. Batal belum disokong.
